# Robot-Voice-Testing

Subproject to General-Kalani-Project regarding voice testing

Goal -> Create voice for General Kalani

## Options:

- Qwen Voice Cloning from original voice samples
    - good outputs
    - takes too long to create response (~ 30 secs for 1-2 mid range sentences)

- Piper + VoiceBox package
    - VoiceBox requirements:
        - read docs!!! Important for tts installations: https://github.com/austin-bowen/voicebox/
        - if not installed, install through powershell: ```winget install Gyan.FFmpeg```
        - if you want to use google tts https://docs.cloud.google.com/docs/authentication/set-up-adc-local-dev-environment

- Piper + PedalBoard package
